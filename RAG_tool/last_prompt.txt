## Event A3 Explanation

**TS 38.331 | Release 17 | Section 2 | Page 1242**

Event A3 is defined as:

> "Neighbour becomes amount of offset better than PCell/PSCell"

### Parameters

Event A3 uses the following parameters:

- **a3-Offset**: Offset value(s) to be used in the triggering condition. The actual value is field value × 0.5 dB
- **reportOnLeave**: Boolean indicating whether to report when leaving the event condition
- **hysteresis**: Hysteresis value to prevent reporting oscillations
- **timeToTrigger**: Time period that the condition must be continuously satisfied before triggering
- **useAllowedCellList**: Boolean indicating whether to use the allowed cell list

### ASN.1 Definition

```
eventA3 SEQUENCE {
  a3-Offset MeasTriggerQuantityOffset,
  reportOnLeave BOOLEAN,
  hysteresis Hysteresis,
  timeToTrigger TimeToTrigger,
  useAllowedCellList BOOLEAN
}
```

### Trigger Condition

The event is triggered when:
```
Neighbour cell measurement + a3-Offset > PCell/PSCell measurement
```

Where:
- `a3-Offset` is in the range -30..30 (actual value = field value × 0.5 dB)
- The condition must be continuously satisfied for the duration specified by `timeToTrigger`
- Hysteresis is applied to prevent rapid triggering

### Usage

Event A3 is commonly used for handover decisions, where the UE reports when a neighboring cell becomes sufficiently better than the serving cell (after applying the offset), indicating that a handover may be beneficial.

Event A3 is used when the **neighboring cell's measurement (Mn) becomes better than the serving cell's measurement (Mp) after applying an offset (a3-Offset)**. This event is triggered when the following conditions are met:  

1. **Entering Condition**:  
   `Mn + Ofn + Ocn - Hys > Mp + Ofp + Ocp + Off`  
   - `Mn`: Neighboring cell's measurement (RSRP, RSRQ, or RS-SINR).  
   - `Ofn`: Measurement object-specific offset for the neighbor.  
   - `Ocn`: Cell-specific offset for the neighbor.  
   - `Hys`: Hysteresis value to prevent oscillations.  
   - `Mp`: Serving cell's measurement.  
   - `Ofp`: Measurement object-specific offset for the serving cell.  
   - `Ocp`: Cell-specific offset for the serving cell.  
   - `Off`: a3-Offset (applied to the neighbor).  

2. **Leaving Condition**:  
   `Mn + Ofn + Ocn + Hys < Mp + Ofp + Ocp + Off`  

### Key Use Cases:  
- **Handover Decisions**: Indicates a neighboring cell is sufficiently better than the serving cell (after offset), prompting a potential handover.  
- **Network Optimization**: Monitors cell quality differences to optimize load balancing or resource allocation.  

### Parameters:  
- `a3-Offset`: Offset applied to the neighbor (range: -30..30, actual value = field value × 0.5 dB).  
- `hysteresis`: Prevents rapid triggering/leaving.  
- `timeToTrigger`: Duration the condition must persist before triggering.  
- `useAllowedCellList`: Determines if the allowed cell list is used for neighbor selection.  

### Example Scenario:  
If a neighboring cell’s RSRP (Mn) is 10 dBm, and the serving cell’s RSRP (Mp) is 8 dBm, with `a3-Offset = 2` (1 dB), the entering condition becomes:  
`10 + Ofn + Ocn - Hys > 8 + Ofp + Ocp + 1`.  
If this holds, the UE reports the event, signaling a potential handover candidate.

- **TS 38.331 | Release 17 | Section 2 | Page 1242**  
- **ASN.1 Definition**: `eventA3` includes `a3-Offset`, `reportOnLeave`, `hysteresis`, `timeToTrigger`, and `useAllowedCellList`.
